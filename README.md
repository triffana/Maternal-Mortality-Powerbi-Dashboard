# Maternal Mortality Power BI Dashboard

An interactive Power BI dashboard for analyzing global maternal mortality trends, country-wise Maternal Mortality Ratio (MMR), and data sources from 2014–2023.

## 📊 Dashboard Overview

This dashboard provides a visual analysis of maternal mortality across different countries and years.

### Key Metrics
- Average Maternal Mortality Ratio (MMR)
- Maximum MMR
- Minimum MMR
- Total Number of Countries
- Latest Available Year

### 📈 Visualizations
- Maternal Mortality Trend (2014–2023)
- Top 10 Countries by Maternal Mortality
- Top 10 Lowest Maternal Mortality Countries
- Country-wise MMR Analysis
- Data Source Distribution
- Interactive Country and Year Filters
- Global Map Visualization

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📂 Dataset

The dashboard uses maternal mortality data containing:
- Country Code
- Country Name
- Year
- MMR
- Unit of Measurement
- Data Source

## 🎯 Objective

The objective of this project is to transform maternal mortality data into an interactive dashboard that helps users understand global and country-level mortality patterns and identify countries with higher and lower maternal mortality rates.
